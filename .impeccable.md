# All-Serve Supply — Impeccable Design Context

## Design Context

### Users
Primary: a restaurant, food-truck, or catering business owner evaluating
All-Serve as a **new** wholesale supplier — deciding whether to trust this
vendor before requesting a quote, not yet a repeat customer. They arrive on
both mobile (quick look, on-the-go) and desktop (a more deliberate review
before committing to a supplier relationship), and CLAUDE.md is explicit
that the desktop view especially needs to read as established and credible
to this audience, not just be a stretched phone layout.

Secondary: existing customers reordering supplies quickly. The site should
stay efficient for them, but layout and copy decisions should default to
building trust first when the two goals conflict — see Design Principles.

Technical level: general small-business owners/staff, not necessarily
tech-savvy. No account system, no login — the whole flow is built around
that lower-friction, lower-trust-required starting point.

### Brand Personality
**Professional & established.** Plainspoken and reassuring rather than
flashy — confident enough to feel like a real, stable business worth a
recurring order relationship, without tipping into stylized/trendy design
(CLAUDE.md rules that out explicitly) or bare-bones industrial/warehouse
starkness either. It sits deliberately between those two poles.

The real logo (`images/logo/logo.svg`) sets the tone: a bold red
fork-and-spoon mark (`#ef2e32` icon front, `#b92f28` icon back) with a
black "ALL-SERVE SUPPLY" wordmark and a small "RESTAURANT & INDUSTRIAL
SUPPLIER" tagline (industrial supply is a real, near-term expansion for the
client, not just legacy copy). No named reference sites were given — the
governing description is the 2-3 word brand personality above, applied
consistently.

### Aesthetic Direction
- **Light mode only, by design** — not an oversight. The one intentional
  dark surface is the footer band (`.site-footer`, near-black), which uses
  a separate reversed/knockout logo (`images/logo/inverted-logo.svg`,
  white + light gray) rather than a site-wide dark theme.
- **Mobile-first**, 375px baseline, scaling up through two breakpoints only
  (640px tablet, 1024px desktop) — no max-width queries.
- **Desktop must be an intentional upgrade, not a stretch**: multi-column
  layouts (split hero, wider catalog grid, sidebar panels), roughly double
  the vertical rhythm, more generous side padding — never just the mobile
  page scaled wider.
- **System font stack only** (`--font-body`), no webfonts — fast load is a
  stated priority and CLAUDE.md requires asking before adding any
  dependency, fonts included.
- **Restrained visual language**: one accent color family (red, 5 steps)
  plus neutrals, 4px-based spacing scale (`--space-1`…`--space-8`), a
  single 4px corner radius (`--radius`) used everywhere, minimal shadows.
  Decoration stays in service of clarity, never flair for its own sake.
- **Accent color is sourced from the real logo** (resolved — was previously
  a mockup guess). `--color-accent` is the exact icon-back/tagline red
  (`#b92f28`, `oklch(52% 0.176 28)`); the other steps are a computed scale
  at the same hue. The brighter icon-front red (`#ef2e32`) is deliberately
  not used as a token — it doesn't leave enough room for white button text
  to hit 4.5:1 AA — see the comment above `:root` in `css/styles.css`.

### Design Principles
1. **Trust over speed.** The primary visitor is evaluating a new supplier
   relationship, not power-reordering — when a layout or copy decision has
   to choose, favor the version that reads as more credible/reassuring
   (clear "why us" reasoning, polished presence) over the version that's
   merely fastest to click through.
2. **Desktop is a deliberate upgrade, not a stretch.** Every new page or
   section needs real desktop-specific layout thinking — multi-column
   composition, intentional use of extra space — never a mobile layout
   just scaled up. This is a hard requirement, not a nice-to-have.
3. **Restrained, utility-first visual language.** No stylized/trendy
   treatments, no webfonts, minimal shadows or rounding. One accent color
   used purposefully (current-state emphasis, primary actions) rather than
   decoratively; neutrals carry everything else.
4. **Never imply a real-time transaction.** This is a content/trust rule
   baked into the brand, not just a legal safeguard: copy and UI must
   always read as a request a person will follow up on — "Request a
   Quote," never "Buy," "Checkout," or "Order Now."
5. **One accent, correctly sourced.** Apply the brand red only to
   actionable or current-state elements (primary CTAs, active nav,
   highlights), never as pure decoration. The token value is now the real
   logo's red (`#b92f28`), not a guess — future color changes should stay
   anchored to the logo rather than drift from it.
